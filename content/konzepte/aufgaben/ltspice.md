# Simulation

Dokumentiere die Messung mit einem Bericht.

1) Simuliere mit LTSpice eine OP basierten, invertierenden Verstärker. Dimensioniere die Verstärkung mit Faktor 100.

2) Mache eine Zeitsimulation und zeige das Ausgangssignal bei einem Eingangssignal von einem 1kHz, 20mV Sinus.

3) Baue den Verstärker so um, dass er zusätzlich eine Tiefpasscharakteristik erhält. Dimensioniere die Grenzfrequenz bei 10kHz.

4) Simuliere einen Frequenz Sweep und zeichne das Bode Diagramm der Schaltung auf. Stimmt die Grenzfrequenz?
