# Git Aufgabe

Voraussetzung: Du solltest wissen, warum man ein Versionskontrollsystem verwendet und die Grundlagen von GIT kennen. Das Tutorial hilft dir zu prüfen ob du das wichtigste verstanden hast.

Arbeite dich durch das Tutorial: [learngitbranching.js.org](https://learngitbranching.js.org)

Mache mindestens die ersten drei Levels (Einführung, Eine Stufe höher und Code umherschieben), wenn Zeit und Freude übrig bleibt, auch Level 4 (Eine bunte Mischung).
