# Git Aufgabe

Git ist das am weitesten verbreitete Versionskontrollsystem. Diese Aufgabe prüft und vertieft dein Wissen über die wichtigsten Git-Konzepte mit einem interaktiven Tutorial.

Voraussetzung: Du solltest wissen, warum man ein Versionskontrollsystem verwendet, und die Grundlagen von Git kennen. Das Tutorial hilft dir zu prüfen, ob du das Wichtigste verstanden hast.

Arbeite dich durch das Tutorial: [learngitbranching.js.org](https://learngitbranching.js.org)

Mache mindestens die ersten drei Levels ("Einführung", "Eine Stufe höher" und "Code umherschieben"). Wenn Zeit und Freude übrig bleiben, auch Level 4 ("Eine bunte Mischung").

- Schwierigkeit: Leicht
- Semester: 1-4
- Material: Computer mit Browser, Zugang zu learngitbranching.js.org
- Abgabe: Abschluss der Levels (Screenshots) und pro Level eine kurze Reflexion (1–2 Sätze): Was war neu für dich? Was war verwirrend?
