# Aufgabe I2C

Nimm das STM32 Devkit und nimm den Temperatur und Fechtsensor SHT31 von Sensorion in Betrieb. Lies Luftfeuchtigkeit und 
Temperatur aus und sende das Ergebnis per UART an den Computer. Du kannst die STM32 Cube MX Bibliotheken verwenden, sonst aber keine weiteren Bibliotheken, schreibe den Code für den Sensor selbst.

Zeichne die Kommunikation für eine Messung per Logik Analyzer auf und zeichne alle wichtigen Elemente. 

Dokumentiere diese Aufgabe in einem kurzen Bericht.
