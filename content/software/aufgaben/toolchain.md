# Aufgabe Toolchain

Recherchiere was alles passiert damit ein C Computer Programm, das als Text getippt wird, schlussendlich von einem Mikrocontroller ausgeführt werden kann. Erstelle eine Bericht und beschreibe die wesentlichen Programme und Arbeitsschritte die ausgeführt werden, inklusive dem Gerät welches den Code auf den Mikrocontroller lädt.
